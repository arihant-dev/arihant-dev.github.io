Forest BD Viewer

FEATURED

I wanted to explore how GIS data works at scale, so I built a full-stack app for querying and visualizing French forest biodiversity data (BD Forêt V2) across Île-de-France. Go backend serves spatial tiles via GraphQL; Next.js frontend renders multi-level Mapbox layers with polygon-based analysis.

  • Zoom-dependent layer switching: regions → departments → communes → forest types → cadastre parcels
  • Polygon analysis: area computation, forest coverage stats, TFV breakdown, top-8 species by hectare
  • Redis-cached MVT tile serving (24h/7d TTL) backed by PostGIS spatial queries
  • JWT auth-gated endpoints, context-based EN/FR i18n
Browser (Next.js/React/Mapbox GL JS) | | HTTP/GraphQL v Go API Server (Echo + gqlgen) | +---> PostgreSQL/PostGIS (spatial data, BD Foret V2) +---> Redis (MVT tile cache, 24h/7d TTL) +---> JWT Auth (stateless token validation) | v Docker Compose (app + db + cache)
